# התוכנית הסופית: כל ההחלטות והנימוקים

עודכן: 1.11.2026. זו **נקודת האמת היחידה לבנייה**. `docs/features-plan.md` הוא יומן החלטות היסטורי (כולל החלטות שבוטלו), ו-`DECISIONS.md` מכיל את ההחלטות הארכיטקטוניות בפורמט המלא (חלופות ונימוקים באנגלית).

**מקור כל החלטה:** 👤 המשתמש החליט (שאלה ותשובה) · ✅ המלצה שהמשתמש אישר · 🔧 נגזר מבדיקה מול ה-CLI/השער (נימוק עובדתי) · ⚠️ התאמה שלי שלא נשאלה במפורש (לאישור).
