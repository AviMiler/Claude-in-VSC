בדיקה: האם התוסף יכול לגשת לשרת המודלים מתוך VS Code
====================================================
קובץ עצמאי: הסבר והקוד המלא של תוסף בדיקה קטן (3 קבצים). אין צורך בגיטהאב או באינטרנט.

המטרה: להוכיח שקוד שרץ בתוך VS Code (ב-Extension Host, כמו התוסף האמיתי) מצליח לפנות
לשער המודלים ב-http://172.27.5.5:11436, ולא רק PowerShell. חשוב כי VS Code יכול לעבור דרך
הגדרות פרוקסי אחרות מהטרמינל. הבדיקה גם פונה לנקודות של LiteLLM שעשויות להחזיר יכולות
וחלון הקשר לכל מודל (ראייה, תמיכה בכלים, max_input_tokens), ובודקת ספירת טוקנים.

הבדיקה היא קריאה בלבד (GET, וקריאה אחת POST לספירת טוקנים בלי להפעיל מודל). לא נכתב
דבר בשרת, והיא לא מפעילה את המודל.


חלק א. הכנה
----------------------------------------------------
1. צור תיקייה, למשל C:\gateway-probe
2. בתוכה שלושה קבצים, כל אחד נוצר ב-Notepad (שמירה בסוג "כל הקבצים", קידוד UTF-8):
     package.json     (הקוד בחלק ה)
     probe.js         (הקוד בחלק ו)
     extension.js     (הקוד בחלק ז)
   הקוד כולו ב-ASCII, ללא עברית.
3. בדיקת תקינות (אמורה לא להדפיס שגיאה):

       cd C:\gateway-probe
       node --check probe.js
       node --check extension.js


חלק ב. שלב 1: הרצה רגילה בטרמינל (השוואה)
----------------------------------------------------
    cd C:\gateway-probe
    node probe.js

הסקריפט מדפיס שורה לכל נקודה: OK או FAIL, קוד, זמן, וסיכום (למשל רשימת המודלים והיכולות).
את התוצאה המלאה הוא שומר בקובץ gateway-probe-result.json בתיקייה.
זו נקודת ההשוואה. אם בשלב הבא הכול נכשל ופה הכול עובד, הבעיה היא ב-VS Code (פרוקסי).


חלק ג. שלב 2: הרצה מתוך VS Code
----------------------------------------------------
1. פתח PowerShell והרץ:

       code --extensionDevelopmentPath=C:\gateway-probe

   ייפתח חלון VS Code חדש ("Extension Development Host") שבו תוסף הבדיקה פעיל.
2. בחלון החדש: F1 (או Ctrl+Shift+P) והקלד:   Gateway Probe: Run   ואנטר.
3. נפתח ערוץ הפלט "Gateway Probe" עם התוצאות (אותה צורה כמו בטרמינל, ובנוסף שורת
   הסביבה: גרסת VS Code, הגדרות הפרוקסי של VS Code).
4. מופיעה הודעה עם שני כפתורים: "Copy summary" (מעתיק את הסיכום ללוח) ו-"Open full result"
   (פותח את הקובץ המלא, שנשמר ב-%TEMP%\gateway-probe-result-extension-host.json).
5. אם הכתובת או המודל שונים, אפשר לשנות בהגדרות: gatewayProbe.baseUrl, gatewayProbe.apiKey,
   gatewayProbe.model.


חלק ד. מה לשלוח חזרה
----------------------------------------------------
1. הפלט של שלב 1 (node probe.js), כולל שורות FAIL ושגיאות.
2. התוכן של ערוץ הפלט "Gateway Probe" משלב 2 (הכפתור Copy summary, ואז הדבקה בשיחה).
   אם נקודות מסוימות מחזירות רשימות ארוכות, מספיק הסיכום.
3. אם יש הבדל בין שלב 1 לשלב 2 (למשל הכול עובד בטרמינל ונכשל בתוך VS Code), ציין זאת.

איך נקרא את התוצאה:
  - GET /v1/models: עובד מתוך VS Code = התוסף יכול לשלוף רשימת מודלים.
  - GET /v1/model/info (או /model_group/info או /public/model_hub): אם יש בהם שדות כמו
    max_input_tokens, supports_vision, supports_function_calling, נקבל יכולות וחלון הקשר
    לכל מודל ונוכל לסנן מודלים שאינם תומכים בכלים.
  - POST /utils/token_counter: ספירת טוקנים מדויקת למד ההקשר.
  - FAIL 401: הנקודה דורשת מפתח אחר מ-ollama. FAIL 404/405: אינה זמינה בשער הזה.
  - שגיאות כמו ECONNREFUSED, ETIMEDOUT או ENOTFOUND: חסימת רשת או פרוקסי.

// Gateway probe core (plain Node, no dependencies). Used by extension.js and runnable alone:
//   node probe.js [--url http://172.27.5.5:11436] [--key ollama] [--model qwen3.8:27b] [--out result.json]
const http = require('http');
const https = require('https');
const os = require('os');
const path = require('path');
const fs = require('fs');

const MAX_BODY = 200000;

function viaHttp(urlStr, { method = 'GET', headers = {}, body, timeoutMs = 15000 } = {}) {
  return new Promise((resolve) => {
    const t0 = Date.now();
    let u;
    try { u = new URL(urlStr); } catch (e) { return resolve({ ok: false, error: 'bad url: ' + urlStr, ms: 0 }); }
    const lib = u.protocol === 'https:' ? https : http;
    const req = lib.request({ hostname: u.hostname, port: u.port, path: u.pathname + u.search, method, headers }, (res) => {
      const chunks = [];
      res.on('data', (c) => chunks.push(c));
      res.on('end', () => {
        const text = Buffer.concat(chunks).toString('utf8');
        resolve({ ok: res.statusCode >= 200 && res.statusCode < 300, status: res.statusCode, ms: Date.now() - t0, text: text.slice(0, MAX_BODY), bytes: text.length, contentType: res.headers['content-type'] });
      });
    });
    req.setTimeout(timeoutMs, () => req.destroy(new Error('timeout after ' + timeoutMs + ' ms')));
    req.on('error', (e) => resolve({ ok: false, error: [e && e.code, e && e.message].filter(Boolean).join(' '), ms: Date.now() - t0 }));
    if (body) req.write(body);
    req.end();
  });
}

async function viaFetch(urlStr, { method = 'GET', headers = {}, body, timeoutMs = 15000 } = {}) {
  if (typeof fetch !== 'function') return { ok: false, error: 'global fetch is not available', ms: 0 };
  const t0 = Date.now();
  const ac = new AbortController();
  const timer = setTimeout(() => ac.abort(), timeoutMs);
  try {
    const res = await fetch(urlStr, { method, headers, body, signal: ac.signal });
    const text = await res.text();
    return { ok: res.ok, status: res.status, ms: Date.now() - t0, text: text.slice(0, MAX_BODY), bytes: text.length, contentType: res.headers.get('content-type') };
  } catch (e) {
    return { ok: false, error: [e && e.name, e && e.message, e && e.cause && (e.cause.code || e.cause.message)].filter(Boolean).join(' '), ms: Date.now() - t0 };
  } finally { clearTimeout(timer); }
}

function summarize(name, text) {
  let json;
  try { json = JSON.parse(text); } catch { return { note: 'not JSON', head: String(text).slice(0, 200) }; }
  const out = { topKeys: json && typeof json === 'object' ? Object.keys(json).slice(0, 12) : typeof json };
  const arr = Array.isArray(json) ? json : (Array.isArray(json && json.data) ? json.data : null);
  if (arr && typeof arr[0] === 'string') {
    out.count = arr.length;
    out.values = arr.slice(0, 60);
  } else if (arr) {
    out.count = arr.length;
    const first = arr[0] || {};
    out.firstItemKeys = Object.keys(first).slice(0, 20);
    if (first.model_info) out.firstItemModelInfoKeys = Object.keys(first.model_info).slice(0, 40);
    out.items = arr.map((m) => {
      const mi = m.model_info || m;
      const pick = {};
      for (const k of ['id', 'model_name', 'model_group', 'max_input_tokens', 'max_tokens', 'supports_vision', 'supports_function_calling', 'supports_reasoning', 'supports_tool_choice', 'context_window']) {
        if (m[k] !== undefined) pick[k] = m[k];
        else if (mi && mi[k] !== undefined) pick[k] = mi[k];
      }
      return pick;
    }).slice(0, 40);
  } else if (json && typeof json === 'object') {
    out.sample = JSON.stringify(json).slice(0, 400);
  }
  return out;
}

function maskProxy(v) { return String(v || '').replace(/\/\/[^@\/]+@/, '//***@'); }

async function runProbe({ baseUrl, apiKey, model, timeoutMs = 15000, extra = {} }) {
  const base = String(baseUrl).replace(/\/+$/, '');
  const auth = { Authorization: 'Bearer ' + apiKey };
  const jsonHeaders = { ...auth, 'Content-Type': 'application/json' };
  const tcBody = JSON.stringify({ model, messages: [{ role: 'user', content: 'hello world' }] });
  const checks = [
    ['GET /v1/models (no key)', 'GET', '/v1/models', {}],
    ['GET /v1/models (key)', 'GET', '/v1/models', auth],
    ['GET /v1/model/info', 'GET', '/v1/model/info', auth],
    ['GET /model_group/info', 'GET', '/model_group/info', auth],
    ['GET /public/model_hub', 'GET', '/public/model_hub', {}],
    ['GET /utils/supported_openai_params', 'GET', '/utils/supported_openai_params?model=' + encodeURIComponent(model), auth],
    ['POST /utils/token_counter', 'POST', '/utils/token_counter', jsonHeaders, tcBody],
    ['GET /routes', 'GET', '/routes', auth],
  ];
  const env = {
    node: process.version,
    electron: process.versions.electron || null,
    platform: process.platform + ' ' + os.release(),
    proxyEnv: Object.fromEntries(['HTTP_PROXY', 'HTTPS_PROXY', 'NO_PROXY', 'http_proxy', 'https_proxy', 'no_proxy'].filter((k) => process.env[k]).map((k) => [k, maskProxy(process.env[k])])),
    ...extra,
  };
  const results = [];
  for (const [name, method, p, headers, body] of checks) {
    const url = base + p;
    const h = await viaHttp(url, { method, headers, body, timeoutMs });
    const entry = { name, url, http: { ok: h.ok, status: h.status, ms: h.ms, bytes: h.bytes, error: h.error, contentType: h.contentType } };
    if (h.text !== undefined) entry.summary = summarize(name, h.text);
    if (name === 'GET /v1/models (no key)') {
      const f = await viaFetch(url, { method, headers, body, timeoutMs });
      entry.fetch = { ok: f.ok, status: f.status, ms: f.ms, bytes: f.bytes, error: f.error };
    }
    if (h.text !== undefined) entry.body = h.text;
    results.push(entry);
  }
  return { baseUrl: base, model, when: new Date().toISOString(), env, results };
}

function formatReport(r, includeBodies = false) {
  const lines = [];
  lines.push('Gateway probe ' + r.when + '  ' + r.baseUrl + '  model=' + r.model);
  lines.push('env: ' + JSON.stringify(r.env));
  for (const e of r.results) {
    const h = e.http;
    lines.push('');
    lines.push((h.ok ? 'OK   ' : 'FAIL ') + e.name + '  ->  ' + (h.status || h.error) + '  (' + h.ms + ' ms, ' + (h.bytes || 0) + ' bytes)');
    if (e.fetch) lines.push('     fetch: ' + (e.fetch.ok ? 'OK ' : 'FAIL ') + (e.fetch.status || e.fetch.error) + ' (' + e.fetch.ms + ' ms)');
    if (e.summary) lines.push('     ' + JSON.stringify(e.summary).slice(0, includeBodies ? 6000 : 1500));
  }
  return lines.join('\n');
}

module.exports = { runProbe, formatReport };

if (require.main === module) {
  const argv = process.argv.slice(2);
  const opt = (n, d) => { const i = argv.indexOf('--' + n); return i >= 0 ? argv[i + 1] : d; };
  runProbe({ baseUrl: opt('url', 'http://172.27.5.5:11436'), apiKey: opt('key', 'ollama'), model: opt('model', 'qwen3.8:27b') }).then((r) => {
    const out = path.resolve(opt('out', 'gateway-probe-result.json'));
    fs.writeFileSync(out, JSON.stringify(r, null, 2));
    console.log(formatReport(r));
    console.log('\nFull result written to ' + out);
  });
}

// Dev-only: checks that the VS Code extension host can reach the model gateway.
const vscode = require('vscode');
const fs = require('fs');
const os = require('os');
const path = require('path');
const { runProbe, formatReport } = require('./probe');

function activate(context) {
  const out = vscode.window.createOutputChannel('Gateway Probe');
  context.subscriptions.push(out);
  context.subscriptions.push(vscode.commands.registerCommand('gatewayProbe.run', async () => {
    const cfg = vscode.workspace.getConfiguration('gatewayProbe');
    const http = vscode.workspace.getConfiguration('http');
    const extra = {
      vscode: vscode.version,
      uiKind: vscode.env.uiKind === vscode.UIKind.Desktop ? 'desktop' : 'web',
      remoteName: vscode.env.remoteName || null,
      httpProxy: (http.get('proxy') || '').replace(/\/\/[^@\/]+@/, '//***@'),
      httpProxySupport: http.get('proxySupport'),
      httpProxyStrictSSL: http.get('proxyStrictSSL'),
    };
    out.show(true);
    out.appendLine('Running gateway probe from the extension host ...');
    const r = await vscode.window.withProgress({ location: vscode.ProgressLocation.Notification, title: 'Gateway Probe' }, () =>
      runProbe({ baseUrl: cfg.get('baseUrl'), apiKey: cfg.get('apiKey'), model: cfg.get('model'), extra }));
    const file = path.join(os.tmpdir(), 'gateway-probe-result-extension-host.json');
    fs.writeFileSync(file, JSON.stringify(r, null, 2));
    const text = formatReport(r);
    out.appendLine(text);
    out.appendLine('\nFull result: ' + file);
    const failed = r.results.filter((e) => !e.http.ok).length;
    const pick = await vscode.window.showInformationMessage(
      'Gateway Probe: ' + (r.results.length - failed) + '/' + r.results.length + ' OK. Full result: ' + file,
      'Copy summary', 'Open full result');
    if (pick === 'Copy summary') await vscode.env.clipboard.writeText(text);
    if (pick === 'Open full result') await vscode.window.showTextDocument(vscode.Uri.file(file));
  }));
}
function deactivate() {}
module.exports = { activate, deactivate };
