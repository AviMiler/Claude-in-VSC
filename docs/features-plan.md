# תוכנית עבודה – פיצ'רים של Claude Code ב-VS Code

מקור: `docs/claude-code-vscode-guide-he.html` (24 סעיפים). מגבלות הפרויקט שמשפיעות על כל החלטה (מתוך `spec.md`):

- מכונה offline בסופו של דבר: אין רשת, CDN, פיצ'רי ענן.
- התוסף לא שומר כלום (אין globalState/workspaceState/קבצים). ה-CLI הוא מקור האמת; היסטוריה נקראת מה-transcripts בלבד.
- JS רגיל, בלי build ובלי npm. כל מחרוזת למשתמש בעברית.

## החלטות
מתעדכן אחרי כל שלב.

### שלב 1 – פתיחה, הפעלה ומיקום (הוחלט)
- נקודות כניסה: להוסיף **Open in Terminal** ואייקון **Activity Bar לרשימת סשנים** (תלוי בשלב 4). **Open in New Window** – לא.
- התחברות: אין login (מודל מקומי). **כרטיס בעברית בצ'אט כשה-CLI נכשל** (שגיאת חיבור/לא מחובר): בדיקת ANTHROPIC_BASE_URL ב-`~/.claude/settings.json`, שהשרת המקומי רץ, ו-`claudeLocal.claudePath`, עם כפתור שפותח את settings.json. בלי צ'קליסט היכרות.
- קישורי URI: **ליישם** `vscode://local.claude-local/open` (פרמטרים prompt, session) **עם אישור לפני שליחה**. טקסט נכנס לתיבה, לא נשלח אוטומטית.
- מיקום: **להוסיף שתי הגדרות** – `claudeLocal.preferredLocation` (panel/sidebar) ו-`claudeLocal.lockEditorGroups`.
