# תוכנית עבודה – פיצ'רים של Claude Code ב-VS Code

מקור: `docs/claude-code-vscode-guide-he.html` (24 סעיפים). מגבלות הפרויקט שמשפיעות על כל החלטה (מתוך `spec.md`):

- מכונה offline בסופו של דבר: אין רשת, CDN, פיצ'רי ענן.
- התוסף לא שומר כלום (אין globalState/workspaceState/קבצים). ה-CLI הוא מקור האמת; היסטוריה נקראת מה-transcripts בלבד.
- JS רגיל, בלי build ובלי npm. כל מחרוזת למשתמש בעברית.

## החלטות
מתעדכן אחרי כל שלב.

### שלב 1 – פתיחה, הפעלה ומיקום (הוחלט)
- נקודות כניסה: להוסיף **Open in Terminal** ואייקון **Activity Bar לרשימת סשנים** (תלוי בשלב 4). **Open in New Window** – לא.
- התחברות: אין login (מודל מקומי). **כרטיס בעברית בצ'אט כשה-CLI נכשל** (שגיאת חיבור/לא מחובר): בדיקת ANTHROPIC_BASE_URL ב-`~/.claude/settings.json`, שהשרת המקומי רץ, ו-`claudeLocal.claudePath`, עם כפתור שפותח את settings.json. בלי צ'קליסט היכרות.
- קישורי URI: **ליישם** `vscode://local.claude-local/open` (פרמטרים prompt, session) **עם אישור לפני שליחה**. טקסט נכנס לתיבה, לא נשלח אוטומטית.
- מיקום: **להוסיף שתי הגדרות** – `claudeLocal.preferredLocation` (panel/sidebar) ו-`claudeLocal.lockEditorGroups`.

### שלב 2 – תיבת הפרומפט (הוחלט)
- מצבי הרשאות: להוסיף **מצב Auto** (אם ה-CLI דוחה – הודעה והמצב לא משתנה) ולוודא ש-**/plan ו-/plan open** מופיעים ומעדכנים את הבורר.
- Plan כמסמך: **גרסה ב** – כפתור "פתח בעורך" בכרטיס התוכנית, מסמך Markdown וירטואלי לקריאה בלבד (`TextDocumentContentProvider`, בלי כתיבת קובץ). בלי הערות בשורות; תגובות בתיבה.
- תפריט `/`: **קבוצות + הבחנה בין skills לפקודות מובנות** (לפי נתוני initialize; לבדוק מה ה-CLI מחזיר).
- @-mentions: **קבצים ותיקיות בלבד** (בלי @terminal ובלי @browser).
- תמונות/קבצים: **הדבקת תמונות, גרירת קבצים (Shift), PDF ו-LaTeX** (KaTeX vendored; PDF – ה-CLI קורא, דורש poppler).
  - דרישת המשתמש: אם המודל לא תומך ראייה, להסתיר/לנטרל את הדבקת התמונות.
- בורר מודל: **מתג Thinking + שורת Effort**, עם דרישה: **להציג רק אם רלוונטי** למודל (לבדוק בתשובת initialize אם יש שדות תמיכה; אם אין דרך לדעת – לבדוק התנהגות מול ה-CLI האמיתי לפני יישום). Ultracode – לא.
- כלי עזר: **כפתור העתקה לכל תשובה** + **פאנל /btw** (שאלת צד בלי כלים ובלי להיכנס להיסטוריה). בלי סימניות.
- מחוונים: **מד הקשר + כפתור /compact** ו-**מפת סוכנים** (תלוי בשלב 4). בלי שעון קאש.

### שלב 3 – הקשר מהעורך ו-diff (הוחלט, עם בדיקות מקדימות)
- הקשר אוטומטי (בחירה + קובץ פתוח): **קודם לנסות דרך שרת IDE** (משולב עם שלב 5). אם לא עובד מול ה-CLI האמיתי – **נפילה לחלופה בלי שרת**: צ'יפים מעל התיבה (`קובץ: app.ts`, `שורות 5–10`, אפשר להסיר) והתוסף מוסיף שורת הקשר להודעה בשליחה.
- Alt+K: **כן** (מכניס `@path#שורות` לתיבה הפעילה; תלוי ב-@-mentions משלב 2).
- הגדרות: **`attachSelection`, `attachOpenFile`, `respectGitIgnore`** (כולן ברירת מחדל פעילה).
- diff על עריכות: **קודם לנסות אישור לכל בלוק שינוי בנפרד** (CodeLens אשר/דחה, חזרה ל-CLI כ-`updatedInput`). **בדיקה נדרשת**: האם ה-CLI האמיתי מקבל עריכה חלקית. אם לא – נפילה ל-**diff צד-לצד עם אישור/דחייה של הכל** (`vscode.diff` על מסמך וירטואלי).
- autosave: **להוסיף**, ברירת מחדל פעילה (שמירת העורך אחרי עריכה של Claude).

#### בדיקות שחובה לבצע מול ה-CLI האמיתי לפני יישום (מצטבר)
1. האם `models[]` ב-initialize מכיל שדות על תמיכה ב-effort/thinking/ראייה (שלב 2).
2. אילו שדות `commands[]` מחזיר כדי להבדיל skills מפקודות מובנות (שלב 2).
3. האם שרת IDE (lock file ב-`~/.claude/ide/`) מקבל את הקשר הבחירה מול CLI 2.1.181 (שלב 3).
4. האם `can_use_tool` מקבל `updatedInput` עם עריכה חלקית (שלב 3).

### שלב 4 – סשנים, היסטוריה, Checkpoints, רקע (הוחלט)
- ניהול סשנים: **שינוי שם דרך ה-CLI** (/rename בסשן פתוח; לבדוק שה-CLI כותב כך לקובץ) + **מסננים** (פעיל / ממתין לקלט / הסתיים; זמניים, בלי שמירה). **בלי ארכוב ובלי קבוצות** (נבחר "לא לארכב"; כלל "אין שמירה" נשמר).
- פתיחה מחדש: **Ctrl+Shift+T** (רשימת סשנים סגורים בזיכרון בלבד), **נקודות צבע בלשוניות** (כחול = ממתין להרשאה, כתום = הסתיים בלשונית מוסתרת; האייקון/השם, כי אין API לצבע), **continueAfterReload** – הערה: זה סותר את "אין שחזור אחרי רענון"; בעת היישום לממש כך שאחרי רענון נפתחת רק הצעה "להמשיך את השיחה האחרונה" שנקראת מה-transcripts, בלי מצב שנשמר בתוסף. **לשונית Web – לדלג** (תשתית ענן של Anthropic, אין שרת פנימי).
- Checkpoints: **מלא** – כפתור בכל הודעת משתמש עם fork / rewind code / שניהם + Esc Esc. **בדיקה נדרשת**: תמיכת ה-CLI 2.1.181 ב-rewind (בקשת בקרה). אם אין – רק fork (`--resume --fork-session`).
- רקע: **כפתור "העבר לרקע" + מפת משימות עם עצירה** (אירועי task_started/task_progress, בקשת stop_task; לבדוק מול ה-CLI). מזין גם את מפת הסוכנים משלב 2.
- אזהרה לתיעוד: בעת עדכון ה-spec יש לעדכן את סעיף "Out of scope" ואת סעיף ה-History לפי שלב זה.

#### בדיקות נוספות מול ה-CLI האמיתי
5. האם /rename כותב שם לקובץ ה-jsonl וניתן לקרוא אותו (שלב 4).
6. האם קיימת בקשת rewind ב-CLI 2.1.181 (שלב 4).
7. אילו אירועי task/background נשלחים בפועל (שלב 4).
