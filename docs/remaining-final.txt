חלק ב. הבדיקה החשובה: האם חלון ההקשר המוגדר נאכף (אתה)
----------------------------------------------------
למה: בהגדרות השער (/v1/model/info) המודל qwen3.8:27b מוגדר עם num_ctx = 12288 טוקנים
ו-max_input_tokens = 8192. אבל Claude Code שולח כ-24,700 טוקנים להודעה פשוטה. אם
המגבלה נאכפת, ההוראות של Claude Code נחתכות בשקט (בהתחלה), והמודל עובד על חלק מהן.
זה עלול להסביר התנהגויות מוזרות (למשל מצב תכנון בלי כפתורי אישור).

הפקודה (קריאה בלבד, לא מפעילה כלים; הקריאה הראשונה עלולה להיות איטית כי היא טוענת
את המודל):

    foreach ($n in 2000, 6000, 12000, 25000, 50000) {
      $sw = [Diagnostics.Stopwatch]::StartNew()
      $body = @{ model="qwen3.8:27b"; max_tokens=5; messages=@(@{role="user"; content=(("word " * $n) + "Reply OK")}) } | ConvertTo-Json -Depth 5
      try {
        $r = Invoke-RestMethod -Method Post -Uri http://172.27.5.5:11436/v1/chat/completions -Headers @{Authorization="Bearer ollama"} -ContentType application/json -Body $body -TimeoutSec 900
        "$n words -> prompt_tokens=$($r.usage.prompt_tokens)  ($([int]$sw.Elapsed.TotalSeconds)s)"
      } catch { "$n words -> ERROR $($_.Exception.Message)" }
    }

איך לקרוא את התוצאה:
  - prompt_tokens גדל יחד עם n ואז נעצר בערך קבוע (למשל 12288 או 8192): החלון נאכף
    בערך הזה.
  - prompt_tokens ממשיך לגדול עד 50,000 ויותר: המגבלה לא נאכפת, והחלון האמיתי גדול יותר.
  - ERROR: שלח את הטקסט (למשל "context length exceeded" משמעותו שהשער דוחה במקום לחתוך).
מה לשלוח: כל השורות שהודפסו.

אם החלון נאכף וקטן (פחות מכ-32 אלף): לבקש ממנהל השרת להגדיל. הודעה שאפשר להעביר אליו:

    "ב-LiteLLM, בהגדרת המודל qwen3.8:27b ב-litellm_params יש extra_body.num_ctx=12288
    ו-max_input_tokens=8192. Claude Code שולח כ-25,000 טוקנים בכל בקשה, ולכן ההוראות
    נחתכות. נא להגדיל את num_ctx ל-32768 לפחות (עדיף 65536 אם הזיכרון מאפשר) ואת
    max_input_tokens בהתאם, ולוודא ש-Ollama עצמו מקבל את הערך (או להגדיר
    OLLAMA_CONTEXT_LENGTH)."

אופציונלי: לבדוק ישירות מול Ollama אם הפורט פתוח מהמחשב שלך (השער פונה אליו ב-11435
על מחשב השרת, ייתכן שהוא חסום מבחוץ):

    Invoke-RestMethod http://172.27.5.5:11435/api/ps | ConvertTo-Json -Depth 5

ובמחשב השרת עצמו:   ollama ps   (בעמודה CONTEXT מופיע החלון בפועל).
