1. פתיחה והפעלה

  • אייקון Spark בסרגל הכלים של העורך (מופיע כשיש קובץ פתוח).
  • אייקון ב-Activity Bar שפותח את רשימת הסשנים.
  • פריט בסרגל המצב "✻ Claude Code", שעובד גם בלי קובץ פתוח.
  • פקודות ב-Command Palette: Open in New Tab, Open in Side Bar, Open in Terminal, Open in New Window.
  • אפשר לגרור את הפאנל לסרגל צד משני, לסרגל ראשי או לאזור העורך. נעילת קבוצות העורך נשלטת ב-lockEditorGroups.
  • מסך התחברות עולה בפתיחה הראשונה ובשגיאות "Not logged in". צ'קליסט ההיכרות ניתן להסתרה (hideOnboarding).
  • קישורי URI: vscode://anthropic.claude-code/open פותח לשונית (עם פרמטרים prompt ו-session), ו-vscode://anthropic.claude-code/install-plugin פותח את דיאלוג התוסף.

2. תיבת הפרומפט

מצבי הרשאות

  • Auto: מסווג מודל בודק את רוב הפעולות.
  • Manual: שואל לפני עריכות ופקודות רוב.
  • Plan: מציע תוכנית וממתין לאישור. התוכנית נפתחת כמסמך Markdown עם הערות.
  • Edit automatically: מאשר עריכות אוטומטית.
  • Bypass permissions: מופיע רק כשמוגדר allowDangerouslySkipPermissions.

תפריט הפקודות (/)

  • Customize: skills (/skills), סגנונות פלט, Hooks, Permissions (Allow / Ask / Deny), זיכרון אוטומטי, ועורך CLAUDE.md.
  • Context: /status, /sandbox, /chrome, /export.
  • Settings: מתג Remote Control לכל הסשנים, מצב Focus view, /logout, ו-/bug או /feedback (נשמר ארכיון מקומי ב-~/.claude/feedback-bundles/).

פיצ'רים נוספים בתיבה

  • /plan נכנס למצב תוכנית, ו-/plan open פותח את קובץ התוכנית.
  • בורר מודל עם שורת Effort ומתג Ultracode (כשזמין).
  • /btw לשאלות צד בפאנל נפרד. נשמרות 20 האחרונות.
  • העתקת תשובות עם /copy (ו-/copy 2 לתשובה קודמת), וסימניות עם /bookmarks.
  • שורת קבצים שנשלחו מ-Claude ב-Remote Control, ומד הקשר עם /compact.
  • שעון קאש הפרומפטים מציג את הזמן שנותר לפני תפוגה, ונצבע באדום כשפג התוקף.
  • מפת סוכנים (או /tasks) להצגת תתי-סוכנים ומשימות ברקע, עם אפשרות עצירה.
  • מתג Thinking לחשיבה מורחבת.
  • Shift+Enter לשורה חדשה. הדבקת תמונות וגרירת קבצים עם Shift.
  • @-mentions: קבצים, תיקיות (עם / בסוף), @terminal:name לפלט טרמינל, ו-@browser לדפדפן.
  • קריאת עמודים מסוימים מ-PDF (דורש poppler-utils). רינדור LaTeX בתשובות.

3. הקשר מהעורך

  • קוד מסומן נשלח אוטומטית, והסרגל התחתון מציג את מספר השורות.
  • הקובץ הפתוח נשלח כהקשר, ושמו מופיע.
  • Option+K (Mac) או Alt+K מוסיף הפניה כמו @app.ts#5-10.
  • ההגדרות attachSelection ו-attachOpenFile מכבות את ההקשר האוטומטי.
  • טקסט מקבצים שמוחרגים או ב-.gitignore לא מוצג בפאנל, ונשלח רק הנתיב.

4. בדיקת שינויים

  • תצוגת הבדלים צד לצד. במצב Manual אפשר לקבל או לדחות כל שינוי.
  • כפתורים "Accept this change" ו-"Reject this change" לכל שינוי (לא מוצגים מעל 100 שינויים).
  • פקודות: Accept Change at Cursor ו-Reject Change at Cursor.

5. סשנים והיסטוריה

  • היסטוריית סשנים עם חיפוש ושתי לשוניות: Local ו-Web (סשנים בענן).
  • המשך שיחה, שינוי שם, ארכוב וביטול ארכוב. ארכוב אוטומטי אחרי 14 ימי חוסר פעילות (archiveInactiveSessions).
  • קבוצות סשנים עם שם, ניתנות לכיווץ ונשמרות לכל תיקיית עבודה.
  • מסננים: Active, Needs input, Working, Completed, Open, Closed.
  • Ctrl/Cmd+Shift+T לפתיחת סשן שנסגר.
  • נקודות צבע בלשוניות: כחול לבקשת הרשאה, כתום לסשן שהסתיים בלשונית מוסתרת.
  • continueAfterReload ממשיך שלב שנקטע אחרי רענון.
  • משיכת סשן מהענן דרך לשונית Web, ו"Open worktree" בבאנר של worktree.

6. Checkpoints וחזרה לאחור

ריחוף על הודעה מציג כפתור חזרה עם שלוש אפשרויות: fork conversation, rewind code, או fork and rewind. בתפריט /rewind (או Esc Esc) יש גם סיכום מהנקודה הזו או עד אליה.

7. עבודה ברקע

  • כפתור Run in background מופיע מתחת לפקודה ארוכה או לתת-סוכן.
  • /tasks פותח את מפת הסוכנים: משימות, מוניטורים ותתי-סוכנים, עם פלט חי ועצירה.

8. שימוש וחשבון

  • /usage פותח דיאלוג חשבון ושימוש: פסי שימוש בתוכנית, פילוח לפי skills, תתי-סוכנים, תוספים ו-MCP, והמלצות עם כפתור Fix.
  • מעבר בין יום לשבוע (Day / Week). למשתמשי API מוצגת עלות הסשן.

9. תצוגה

  • Focus view (Ctrl/Cmd+Option+F) מסתיר קריאות כלים, תוצאות וחשיבה.
  • חותמות זמן (showMessageTimestamps), מילות ספינר מותאמות (spinnerVerbs), וגלילה לסוף בעת שליחה (scrollToBottomOnSend).
  • Terminal mode (useTerminal) מציג את הפאנל כממשק טרמינל.

10. תוספים

  • דיאלוג /plugins עם לשוניות Plugins ו-Marketplaces: הפעלה וכיבוי, התקנה, הגדרת אפשרויות והסרה. שגיאות טעינה מוצגות עם הסיבה.
  • היקף התקנה: לי (user), לפרויקט (project) או מקומי (local).
  • ב-"Disable for me" או "Disable for everyone" אפשר לכבות תוסף משותף.
  • Mods: תוספים שמציירים פאנלים, הודעות קופצות, שורות מצב והודעות בפאנל (דורש גרסה 2.1.299 ומעלה).

11. דפדפן (Chrome)

  • הקלדת @browser בפרומפט, או תפריט כלי דפדפן.
  • דורש את התוסף Claude in Chrome בגרסה 1.0.36 ומעלה. Claude משתמש בלשונית ובהתחברות הקיימת בדפדפן.
  • מתג Enabled by default משותף ל-CLI ול-VS Code: מחבר כל סשן בהפעלה (מגרסה 2.1.287).
  • הרשאות לאתרים מנוהלות בהגדרות תוסף Chrome.

12. Git

Claude יכול לבצע commit, לפתוח Pull Request ולסכם שינויים בתוך ה-repository.

13. שרתי MCP

דיאלוג /mcp מאפשר הוספה, הסרה, הפעלה וכיבוי, חיבור מחדש, והתחברות OAuth לשרתים מוגדרים.

14. שילוב IDE

  • שרת מקומי על ws://127.0.0.1 בפורט אקראי, מאומת בקובץ נעילה ב-~/.claude/ide/.
  • כלים: getDiagnostics (קורא את לוח הבעיות) ו-executeCode (מריץ Python בנוטבוק Jupyter, לאחר אישור).
  • שיתוף בחירה וקובץ פתוח עם ה-CLI.

16. נגישות

  • הכרזות לקורא מסך על תשובות, בקשות הרשאה, שינויי סטטוס, הודעות בתור ושגיאות.
  • ניווט לפי כותרות בין תורות, ותוויות דוברים ("You", "Claude").
  • בהרשאות: חצים שמאלה וימינה משנים את יעד השמירה.
  • מצב קורא מסך מלא קיים ב-CLI בלבד (--ax-screen-reader), ובתוסף ההכרזות פעילות אוטומטית.
  • הגדרות נוספות: CLAUDE_CODE_ACCESSIBILITY=1 לסמן נראה לזכוכית מגדלת, prefersReducedMotion, וערכות צבע dark-daltonized ו-light-daltonized.

17. הכתבה קולית

  • דורשת התחברות ל-claude.ai. לא זמינה עם מפתח API או ספק צד שלישי, ולא בסשנים מרוחקים (SSH, Dev Container, Codespaces).
  • התמלול אינו צורך הודעות או טוקנים.
  • Hold (ברירת מחדל): מחזיקים רווח כדי להקליט. Tap: לחיצה להתחלה ולחיצה לשליחה. בתצורת Tap השליחה אוטומטית משלוש מילים ומעלה.
  • autoSubmit שולח בעת שחרור המקש. Esc או Ctrl+C מבטלים הקלטה.
  • שפה לפי הגדרת language, או לפי accessibility.voice.speechLanguage של VS Code. ברירת מחדל: אנגלית.
  • ההקלטה נעצרת אחרי 15 שניות של שקט או אחרי שתי דקות.

20. מצב אינטראקטיבי

עריכה והיסטוריה

  • עריכת טקסט: Ctrl+A/E לתחילת שורה וסופה, Ctrl+K ו-Ctrl+U למחיקה, Ctrl+W למחיקת מילה, Ctrl+Y להדבקה, ו-Ctrl+_ לביטול.
  • היסטוריה לפי תיקיית עבודה. חזרה להודעה שנוקתה בלחיצה על Up.

תור הודעות

  • הודעה שנשלחת בזמן ש-Claude עובד נכנסת לתור ולא עוצרת את התור.
  • Ctrl+Enter (או Ctrl+X Ctrl+S) שולח את התור מיד. Up מחזיר הודעות מהתור לעריכה.
  • /model, /effort ו-/fast פועלים מיד גם באמצע עבודה.

הרצה ברקע וכתיבה ישירה

  • Ctrl+B מעביר פקודת Bash לרקע. פקודה שחורגת מהזמן המוגדר עוברת לרקע אוטומטית.
  • מצב Shell עם ! מריץ פקודה ישירות, והפלט נכנס לשיחה.

הצעות ותובנות

  • הצעת הפרומפט הבא מופיעה באפור. Tab או חץ ימינה מקבלים אותה. כיבוי: promptSuggestionEnabled: false.
  • You should know (מוד מובנה, כבוי כברירת מחדל): הערה על דבר שכדאי לשים אליו לב. מופעל עם /plugin enable cc-plugin-you-should-know@builtin.
  • השלמת אימוג'י בקודי :heart:, ובדיקת איות אופציונלית.

diff ו-/btw

  • /diff פותח פאנל הבדלים לצד השיחה במצב fullscreen, או דיאלוג מעל הפרומפט במצב הרגיל. בפאנל אפשר לשאול על קובץ (ask), לבחור תור (T1, T2 ...), ולשנות את בסיס ההשוואה עם Ctrl+X B.
  • /btw שואל שאלת צד בלי כלים ובלי להוסיף להיסטוריה. מתוך השכבה אפשר להעתיק (c) או להפוך לתת-סוכן עם כלים (f).

רשימת משימות, סיכום והמתנה למגבלה

  • רשימת המשימות של Claude מוצגת עם Ctrl+T, ונפרדת מ-/tasks.
  • /recap מציג סיכום קצר. סיכום אוטומטי מופיע אחרי שלוש דקות בהיעדרות.
  • כשמגבלת שימוש של claude.ai עוצרת משימה, Claude ממתין ומתחיל מחדש לאחר האיפוס. Esc מבטל את ההמתנה. כיבוי: autoContinueAtUsageLimit: false.

סטטוס PR

בתחתית מוצג קישור PR עם צבע לפי סטטוס הבדיקה: ירוק לאישור, צהוב לממתין, אדום לבקשת שינויים, אפור לטיוטה.

21. Remote Control

  • הפעלה בפקודה /remote-control (או /rc) בתיבת הפרומפט. אחרי הפעלה מופיע מחוון Remote Control בתחתית, וה-URL של הסשן נשלח לשיחה. הפקודה שוב מנתקת.
  • החיבור מאפשר להמשיך את הסשן מהטלפון או מדפדפן דרך claude.ai/code או אפליקציית Claude. הקוד ממשיך לרוץ במחשב שלך.
  • מכשיר מחובר רואה את השיחה, תתי-סוכנים ודיף. אפשר לשלוח תמונות וקבצים.
  • ההפעלה האוטומטית לכל הסשנים: מתג בתפריט הפקודות, או remoteControlAtStartup.
  • בטרמינל: claude remote-control מפעיל שרת לכמה סשנים, ו-claude --remote-control פותח סשן רגיל עם שליטה מרחוק.

22. Hooks

  • Hooks הם פקודות שמוגדרות בקובץ settings.json ורצות בנקודות קבועות במחזור החיים. /hooks מציג את כל ה-hooks הרשומים.
  • דוגמאות נפוצות: התראת שולחן עבודה כש-Claude מחכה לקלט, עיצוב אוטומטי אחרי עריכה, חסימת עריכה בקבצים מוגנים, ואישור אוטומטי של בקשות מסוימות.
  • סוגי hooks: פקודה (command), מבוסס פרומפט, מבוסס סוכן, ו-HTTP.
  • התראות נתמכות לפי matcher, למשל permission_prompt, idle_prompt ו-agent_completed. matcher ריק מתאים לכולן.

23. הגדרות מנוהלות

  • הגדרות שהארגון מפיץ גוברות על הגדרות המשתמש, הפרויקט והמקומי. יש כמה חריגים מצומצמים.
  • מה שאפשר לשנות גם כשהארגון קבע ברירת מחדל: מודל לסשן (--model) וחלון הדחיסה (--autocompact).
  • בדיקה: /status מציג בשורה Setting sources איזה מקור מנוהל פעיל. שורה Skipped sources מציגה מקורות שנמצאו אבל נעקפו.
  • claude doctor מציג ערכים שנפסלו בבדיקת הסכמה.

24. משימות מתוזמנות ו-/loop

  • /loop מריץ פרומפט במרווחי זמן (למשל 5m או ביטוי cron), או בקצב שClaude בוחר. עוצרים ב-Esc או בבקשה ל-Claude. משימות בסשן פגות אחרי 7 ימים.
  • משימות ענן (לשעבר routines) רצות בתשתית של Anthropic גם כשהמחשב כבוי. הפעלה לפי תזמון, קריאת API, או אירועי GitHub. זמין בתוכניות Pro, Max, Team ו-Enterprise. יוצרים ב-claude.ai/code/routines או עם /schedule.

הערות על המקור

המסמך מבוסס על עמודי התיעוד הרשמיים של Claude Code. חלק מהעמודים נקראו דרך כלי סיכום, ולכן הניסוח עשוי להיות שונה מהמקור. שמות מדויקים, מקשים וגרסאות כדאי לבדוק מול התיעוד לפני שימוש רשמי. תיאור ההתקנה לפי מערכת הפעלה, ספקי הענן וה-gateways לא נכלל, לפי הבקשה.
