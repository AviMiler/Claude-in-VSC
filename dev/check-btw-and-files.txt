בדיקות: /btw ושיוך קבצים לשיחה
==============================

מה זה: שלושה חלקים. חלק א' (/btw מול ה-CLI האמיתי) ידני ב-PowerShell. חלק ב' (@ מול ה-CLI) הוא בדיקה נפרדת
שכבר קיימת: dev/check-at-mention.txt (הריצו אותה לפני חלק ג'). חלק ג' (שיוך קבצים ב-VS Code) ידני.
בכל חלק כתוב מה להעתיק לצ'אט. כמה דקות לכל חלק, וטעינת מודל קרה יכולה לקחת יותר.

------------------------------------------------------------
חלק א' - /btw (שאלה צדדית) מול ה-CLI האמיתי
------------------------------------------------------------
מטרה: לדעת אם /btw קיים בגרסה שלכם, איך הוא מתנהג במצב stream-json (כמו בתוסף), והאם הוא נכנס להיסטוריה.

א.0 גרסת ה-CLI. הריצו:

claude --version

א.1 הדביקו ב-PowerShell את כל הבלוק (אם claudePath שלכם הוא נתיב מלא, שנו את השורה הראשונה):

$claude = 'claude'
$dir = Join-Path $env:TEMP 'cl-btw-test'
New-Item -ItemType Directory -Force $dir | Out-Null
function Msg($t) { @{ type = 'user'; message = @{ role = 'user'; content = @(@{ type = 'text'; text = $t }) } } | ConvertTo-Json -Depth 6 -Compress }
$lines = @(
  (Msg 'Remember the number 4242. Reply with only: OK'),
  (Msg '/btw What number did I ask you to remember? Answer with the number only.'),
  (Msg '/btw Use a tool to list the files in the current folder.'),
  (Msg 'What number did I ask you to remember? Answer with the number only.')
)
Push-Location $dir
$out = $lines | & $claude -p --input-format stream-json --output-format stream-json --verbose
Pop-Location
$sid = $null
foreach ($l in $out) {
  try { $j = $l | ConvertFrom-Json } catch { continue }
  if ($j.type -eq 'system' -and $j.subtype -eq 'init') { $sid = $j.session_id; 'init: btw ברשימת הפקודות = ' + ($j.slash_commands -contains 'btw') + ' | model=' + $j.model }
  elseif ($j.type -eq 'result') { 'result[' + $j.subtype + ']: ' + $j.result }
  elseif ($j.type -eq 'assistant') {
    $t = ($j.message.content | Where-Object { $_.type -eq 'text' } | ForEach-Object { $_.text }) -join ' '
    $u = ($j.message.content | Where-Object { $_.type -eq 'tool_use' } | ForEach-Object { $_.name }) -join ','
    "assistant: טקסט=[$t] כלים=[$u]"
  }
  elseif ($j.type -ne 'stream_event') { 'אחר: ' + $j.type + '/' + $j.subtype }
}
$enc = $dir -replace '[^A-Za-z0-9]', '-'
$tr = Join-Path $env:USERPROFILE ".claude\projects\$enc\$sid.jsonl"
'תמלול: ' + $tr
'שורות בתמלול שמכילות "btw": ' + (Select-String -Path $tr -Pattern 'btw' -SimpleMatch | Measure-Object).Count
'שורות בתמלול שמכילות "4242": ' + (Select-String -Path $tr -Pattern '4242' -SimpleMatch | Measure-Object).Count

איך לקרוא את התוצאה:
- "btw ברשימת הפקודות = False": הפקודה לא קיימת בגרסה שלכם (או לא מוצגת במצב הזה). אין מה לבנות עד שיוסבר.
- תשובת /btw הראשונה (שאלת "איזה מספר") אמורה להיות 4242 אם /btw רואה את הקשר השיחה. אם המודל אומר שאינו יודע:
  /btw בלי הקשר, ובמקרה כזה הפיצ'ר הוא "שאלה כללית בלי זיכרון" ולא "שאלה על מה שקרה".
- ההודעה השלישית (/btw עם בקשה להשתמש בכלי): בעמודה "כלים" אמור להיות ריק. אם מופיע שם כלי, הכלים לא חסומים.
- האם /btw נכנס להיסטוריה: הודעה רביעית (בלי /btw) שואלת שוב על המספר; היא צריכה לענות 4242 (נזכר מההודעה הראשונה).
  מספר השורות עם "btw" בתמלול אומר אם הפקודה והתשובה נשמרו (0 = לא נשמרו, כמו שמצופה מ"שאלה צדדית").
- "אחר:" שורות מראות סוגי אירועים נוספים ש-/btw מחזיר. העתיקו אותן.

א.2 (אופציונלי, במצב אינטראקטיבי, בלי התוסף) האם /btw עובד בזמן ש-Claude עובד:
1. בטרמינל, בתיקייה זמנית: claude
2. בקשו משימה ארוכה, למשל: כתוב סיפור של 40 שורות ועבור עליו אחר כך 3 פעמים.
3. בזמן שהוא עובד, הקלידו /btw מה שם התיקייה הנוכחית? ולחצו Enter.
4. רשמו: האם התשובה הופיעה מיד בלי להפסיק את העבודה? האם המשימה המשיכה?

מה להעתיק לצ'אט: תוצאת claude --version, כל פלט א.1, ותוצאת א.2 (שורה אחת).

הערה: א.1 שולח ארבע הודעות קצרות למודל, ולא נוגע בפרויקט שלכם (התיקייה נוצרת ב-TEMP). מחיקה:
Remove-Item -Recurse $env:TEMP\cl-btw-test

------------------------------------------------------------
חלק ב' - @ מול ה-CLI
------------------------------------------------------------
הריצו את dev/check-at-mention.txt והעתיקו את ארבע שורות "תשובה:" ואת גרסת ה-CLI.
בלי התוצאה שלו, בדיקות ג'.5 עד ג'.7 לא יוכלו להסביר מה קרה.

------------------------------------------------------------
חלק ג' - שיוך קבצים לשיחה, ב-VS Code עם התוסף
------------------------------------------------------------
הכנה: פתחו את התוסף ב-VS Code (code --extensionDevelopmentPath=C:\Users\user\Claude-in-VSC) על פרויקט כלשהו, ופתחו
את היומן: Ctrl+Shift+P ואז "Claude Code Local: הצגת יומן". צרו בפרויקט שני קבצי טקסט: a.txt עם השורה "המילה היא ענבר"
ו-b.txt עם השורה "המילה היא תפוז". שיחה חדשה לכל בדיקה שמצוינת "שיחה חדשה".

ג.1 רשימת @
  1. בתיבת ההודעה הקלידו @ .  צפוי: רשימת קבצים ותיקיות של הפרויקט (בלי קבצים ש-.gitignore מתעלם מהם).
  2. הקלידו חלק משם, ובחרו a.txt עם Enter.  צפוי: בתיבה מופיע @ ואחריו נתיב מלא (C:/...).
  3. בחרו תיקייה מהרשימה.  צפוי: הרשימה מציגה את התוכן הישיר של התיקייה (אפשר לרדת עוד).
  4. ודאו שבחירה מהרשימה לא מפעילה פקודת / ולא שולחת כלום.

ג.2 קיצורים וגרירה
  1. פתחו קובץ בעורך ולחצו Alt+K.  צפוי: @ עם נתיב הקובץ נכנס לתיבה.
  2. גררו קובץ מהסייר לתיבת ההודעה כשמקש Shift לחוץ.  צפוי: @ עם נתיב מלא.
  3. גררו קובץ תמונה מחוץ ל-VS Code אל התיבה (F-11).  צפוי: תמונה מצורפת. אם לא: רשמו, ושורת [drop] מהיומן.

ג.3 מה ה-CLI עושה עם @ (תלוי בחלק ב')
  1. שיחה חדשה. הקלידו @a.txt (מהרשימה) ואחריו: מהי המילה בקובץ? ענו במילה אחת. ושלחו.
  2. צפוי: ענבר. בדקו בשיחה: האם הופיעה שורת כלי "קריאה" (Read) לפני התשובה?
     - ענבר בלי שורת כלי: ה-CLI העלה את הקובץ (@ מורחב).
     - ענבר אחרי שורת כלי קריאה: המודל פתח אותו בעצמו (@ לא הורחב).
  3. שיחה חדשה, @ של תיקייה ואחריו: אילו קבצים יש בתיקייה? צפוי: רשימה בלבד, בלי תוכן הקבצים.

ג.4 כפתור קובץ העבודה (במצב הנוכחי: בורר קבצים; יוחלף בסייר הקבצים של הפרויקט, חבילה I)
  1. שיחה חדשה.  צפוי: בשורת הכלים כפתור "קובץ עבודה: ללא".
  2. לחצו עליו.  צפוי: בורר עם "ללא קובץ", "הקובץ הפתוח עכשיו" (אם יש), וקבצי הפרויקט. בחרו a.txt.
     הכפתור מציג 📄 a.txt.
  3. שלחו: מה המילה בקובץ שהתחלנו ממנו? ענו במילה אחת.  צפוי: ענבר (המודל הונחה להתחיל מהקובץ).
  4. שלחו עוד הודעה: ומה קורה בקובץ הזה אם אני מוסיף שורה? (הוראת ההתחלה לא אמורה לחזור בהודעה השנייה;
     אין דרך לראות זאת ישירות, ולכן חפשו שהתשובה עדיין מתייחסת לקובץ).
  5. שנו את הבחירה ל-b.txt ושלחו: באיזה קובץ מתחילה העבודה? צפוי: b.txt, המילה תפוז.
  6. בחרו "ללא קובץ".  צפוי: הכפתור חוזר ל"קובץ עבודה: ללא", וההודעה הבאה נשלחת כרגיל.

ג.5 ללא שמירה (כמו שהוחלט: בזיכרון בלבד)
  1. בחרו a.txt, שלחו הודעה, ואז סגרו את השיחה ופתחו אותה מחדש מרשימת השיחות (☰).
  2. צפוי: הכפתור "קובץ עבודה: ללא" (הבחירה לא נשמרת). זה תקין לפי ההחלטה, לא תקלה.
  3. טענו מחדש את החלון (Developer: Reload Window).  צפוי: אותו דבר.

ג.6 תמונה בלבד (F-11)
  1. הדביקו תמונה לתיבה (Ctrl+V) בלי לכתוב טקסט.  צפוי: כפתור השליחה פעיל, והשליחה עובדת.
  2. אם המודל לא תומך בתמונות, צפוי הסבר בעברית לפני שגיאת השרת.

מה להעתיק לצ'אט: לכל סעיף ג.* - עבר / נכשל, ואם נכשל מה קרה בפועל ושורות רלוונטיות מהיומן. ב-ג.3 ציינו
איזו מהאפשרויות התקבלה. ב-ג.4 ציינו אם הכפתור והבורר נראים נכון.

הערה: הבדיקות לא משנות את הפרויקט, חוץ משני קבצי הטקסט שיצרתם. ללא התקנות.
