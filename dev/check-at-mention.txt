בדיקה: האם ה-CLI מעלה קובץ שמוזכר עם @ כשהוא רץ במצב stream-json (כמו בתוסף)?
================================================================================

למה: התוסף שולח "@C:/נתיב/קובץ" בהודעה (חיפוש @, Alt+K, כפתור קובץ העבודה). אם ה-CLI מרחיב את זה במצב
stream-json, הקובץ מגיע למודל לבד. אם לא, צריך את ההוראה המפורשת "התחל את העבודה מהקובץ" והמודל יפתח אותו בעצמו.

איך הבדיקה מחליטה: היא יוצרת קובץ עם מילה סודית, ומריצה את ה-CLI כשכלי הקריאה והחיפוש חסומים. אם המודל
עונה את המילה, התוכן הועלה על ידי ה-CLI (@ עובד). אם הוא אומר שאינו יכול לקרוא, @ לא מרחיב.
הבדיקה לוקחת כמה דקות (טעינת מודל), ולא משנה שום דבר בפרויקט שלכם: הקובץ נוצר בתיקיית TEMP.

הרצה: פתחו PowerShell, הדביקו את כל הבלוק הבא (אם claudePath שלכם הוא נתיב מלא ל-claude-bin.exe,
שנו את השורה הראשונה):

$claude = 'claude'
$dir = Join-Path $env:TEMP 'cl-at-test'
New-Item -ItemType Directory -Force $dir | Out-Null
Set-Content -Path (Join-Path $dir 'secret.txt') -Value 'The secret word of this file is PINEAPPLE-7731' -Encoding utf8
$abs = (Join-Path $dir 'secret.txt') -replace '\\','/'
function Ask($label, $text) {
  Write-Host "=== $label" -ForegroundColor Cyan
  $msg = @{ type = 'user'; message = @{ role = 'user'; content = @(@{ type = 'text'; text = $text }) } } | ConvertTo-Json -Depth 6 -Compress
  $out = $msg | & $claude -p --input-format stream-json --output-format stream-json --verbose --disallowedTools 'Read,Glob,Grep,Bash,Edit,Write,WebFetch'
  foreach ($line in $out) { try { $j = $line | ConvertFrom-Json } catch { continue }; if ($j.type -eq 'result') { Write-Host ("תשובה: " + $j.result) } }
}
Push-Location $dir
Ask '1: @ עם נתיב מלא' "@$abs מהי המילה הסודית בקובץ? ענו במילה אחת."
Ask '2: @ עם נתיב יחסי' "@secret.txt מהי המילה הסודית בקובץ? ענו במילה אחת."
Ask '3: בקרה, בלי @ (אמור להיכשל)' "מהי המילה הסודית בקובץ secret.txt שבתיקייה הנוכחית? ענו במילה אחת."
Ask '4: הוראה מפורשת, בלי כלים' "התחל את העבודה מהקובץ @$abs. מהי המילה הסודית בו? ענו במילה אחת."
Pop-Location

איך לקרוא את התוצאה:
- בדיקה 3 (בקרה) חייבת להיכשל (המודל לא יודע את המילה). אם היא מצליחה, הכלים לא נחסמו והבדיקה לא תקפה.
- בדיקה 1 עונה PINEAPPLE-7731: ה-CLI מרחיב נתיב מלא במצב stream-json. התוסף יכול להסתפק ב-@.
- בדיקה 1 נכשלת וגם 4 נכשלת: ה-CLI לא מרחיב, והמודל לא מצליח בלי כלים. זה צפוי, כי בבדיקה הכלים חסומים;
  במקרה כזה בתוסף האמיתי המודל יפתח את הקובץ בעצמו בכלי הקריאה, וההוראה המפורשת היא מה שמנחה אותו.
- בדיקה 2 מראה אם נתיב יחסי עובד (בעבר הוא לא הורחב).

מה להעתיק לצ'אט: את ארבע השורות "תשובה:", ואת גרסת ה-CLI (הרצה של: claude --version).

הערה: הבדיקה שולחת ארבע הודעות קצרות למודל, ושום דבר אחר. מחיקת הקובץ: Remove-Item -Recurse $env:TEMP\cl-at-test
