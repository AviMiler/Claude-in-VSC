חבילת בדיקות מלאה לתוסף "Claude Code Local"
=============================================

הקובץ הזה אוסף את כל הבדיקות שרק אתם יכולים להריץ, ואומר לכל אחת איך מריצים אותה צעד אחר צעד.
עד עכשיו הבדיקות האוטומטיות עברו (162 מתוך 162), אבל שום דבר לא נבדק ב-VS Code אמיתי ומול ה-CLI האמיתי שלכם (גרסה 2.1.246).
המטרה: לדעת מה עובד ומה לא, ולהעתיק לי את התוצאות כדי שאתקן.

כמה זמן: בערך שעה בסך הכל. אפשר לעשות בחלקים. סדר מומלץ: 0, 1, 2, 3, 7, 4, 5, 6.

------------------------------------------------------------
הכנה כללית (קוראים פעם אחת)
------------------------------------------------------------
איך פותחים PowerShell: לחצו על מקש Windows, הקלידו PowerShell, ו-Enter. כל "הדביקו ב-PowerShell" בהמשך
אומר: להעתיק את הבלוק, ללחוץ קליק ימני בחלון (זה מדביק) ו-Enter. אם PowerShell שואל משהו - ענו "Y" או "A".

איך מריצים את התוסף: ב-PowerShell, אחרי cd לתיקיית הפרויקט שלכם שעליו תרצו לעבוד, הריצו:

code --extensionDevelopmentPath=C:\Users\user\Claude-in-VSC

נפתח חלון VS Code חדש ("Extension Development Host") שהתוסף פעיל בו. את כל בדיקות ה-VS Code עושים בחלון הזה.
אם הפקודה code לא מוכרת: ב-VS Code לחצו Ctrl+Shift+P והקלידו "Shell Command: Install 'code' command in PATH".

איך פותחים את היומן של התוסף (לוג): בחלון VS Code לחצו Ctrl+Shift+P, הקלידו "Claude Code Local: הצגת יומן" ו-Enter.
הלוג נפתח בלוח Output. את שורות הלוג מעתיקים מסמנים בעכבר ו-Ctrl+C.

איך מדווחים: לכל בדיקה כתוב בסופה "מה להעתיק". הדביקו לי את זה בצ'אט. לא צריך לעבוד על שום דבר אחר.

בדיקה 2 - האם ה-CLI מעלה קובץ שמוזכר עם @ (כמה דקות)
------------------------------------------------------------
איך מריצים: פתחו PowerShell והדביקו את הבלוק שמופיע בהמשך (תחת 'הרצה').
הסקריפט יוצר קובץ בתיקיית TEMP, שולח ארבע הודעות קצרות למודל, ומדפיס ארבע שורות 'תשובה:'.


למה: התוסף שולח "@C:/נתיב/קובץ" בהודעה (חיפוש @, Alt+K, כפתור קובץ העבודה). אם ה-CLI מרחיב את זה במצב
stream-json, הקובץ מגיע למודל לבד. אם לא, צריך את ההוראה המפורשת "התחל את העבודה מהקובץ" והמודל יפתח אותו בעצמו.

איך הבדיקה מחליטה: היא יוצרת קובץ עם מילה סודית, ומריצה את ה-CLI כשכלי הקריאה והחיפוש חסומים. אם המודל
עונה את המילה, התוכן הועלה על ידי ה-CLI (@ עובד). אם הוא אומר שאינו יכול לקרוא, @ לא מרחיב.
הבדיקה לוקחת כמה דקות (טעינת מודל), ולא משנה שום דבר בפרויקט שלכם: הקובץ נוצר בתיקיית TEMP.

הרצה: פתחו PowerShell, הדביקו את כל הבלוק הבא (אם claudePath שלכם הוא נתיב מלא ל-claude-bin.exe,
שנו את השורה הראשונה):

$claude = 'claude'
$dir = Join-Path $env:TEMP 'cl-at-test'
New-Item -ItemType Directory -Force $dir | Out-Null
Set-Content -Path (Join-Path $dir 'secret.txt') -Value 'The secret word of this file is PINEAPPLE-7731' -Encoding utf8
$abs = (Join-Path $dir 'secret.txt') -replace '\\','/'
function Ask($label, $text) {
  Write-Host "=== $label" -ForegroundColor Cyan
  $msg = @{ type = 'user'; message = @{ role = 'user'; content = @(@{ type = 'text'; text = $text }) } } | ConvertTo-Json -Depth 6 -Compress
  $out = $msg | & $claude -p --input-format stream-json --output-format stream-json --verbose --disallowedTools 'Read,Glob,Grep,Bash,Edit,Write,WebFetch'
  foreach ($line in $out) { try { $j = $line | ConvertFrom-Json } catch { continue }; if ($j.type -eq 'result') { Write-Host ("תשובה: " + $j.result) } }
}
Push-Location $dir
Ask '1: @ עם נתיב מלא' "@$abs מהי המילה הסודית בקובץ? ענו במילה אחת."
Ask '2: @ עם נתיב יחסי' "@secret.txt מהי המילה הסודית בקובץ? ענו במילה אחת."
Ask '3: בקרה, בלי @ (אמור להיכשל)' "מהי המילה הסודית בקובץ secret.txt שבתיקייה הנוכחית? ענו במילה אחת."
Ask '4: הוראה מפורשת, בלי כלים' "התחל את העבודה מהקובץ @$abs. מהי המילה הסודית בו? ענו במילה אחת."
Pop-Location

איך לקרוא את התוצאה:
- בדיקה 3 (בקרה) חייבת להיכשל (המודל לא יודע את המילה). אם היא מצליחה, הכלים לא נחסמו והבדיקה לא תקפה.
- בדיקה 1 עונה PINEAPPLE-7731: ה-CLI מרחיב נתיב מלא במצב stream-json. התוסף יכול להסתפק ב-@.
- בדיקה 1 נכשלת וגם 4 נכשלת: ה-CLI לא מרחיב, והמודל לא מצליח בלי כלים. זה צפוי, כי בבדיקה הכלים חסומים;
  במקרה כזה בתוסף האמיתי המודל יפתח את הקובץ בעצמו בכלי הקריאה, וההוראה המפורשת היא מה שמנחה אותו.
- בדיקה 2 מראה אם נתיב יחסי עובד (בעבר הוא לא הורחב).

מה להעתיק לצ'אט: את ארבע השורות "תשובה:", ואת גרסת ה-CLI (הרצה של: claude --version).

הערה: הבדיקה שולחת ארבע הודעות קצרות למודל, ושום דבר אחר. מחיקת הקובץ: Remove-Item -Recurse $env:TEMP\cl-at-test

בדיקה 3 - /btw מול ה-CLI האמיתי (כמה דקות)
------------------------------------------------------------
איך מריצים: א.1 הוא סקריפט שמדביקים ב-PowerShell (כמו בבדיקה 2). א.2 ידני בטרמינל.

מטרה: לדעת אם /btw קיים בגרסה שלכם, איך הוא מתנהג במצב stream-json (כמו בתוסף), והאם הוא נכנס להיסטוריה.

א.0 גרסת ה-CLI. הריצו:

claude --version

א.1 הדביקו ב-PowerShell את כל הבלוק (אם claudePath שלכם הוא נתיב מלא, שנו את השורה הראשונה):

$claude = 'claude'
$dir = Join-Path $env:TEMP 'cl-btw-test'
New-Item -ItemType Directory -Force $dir | Out-Null
function Msg($t) { @{ type = 'user'; message = @{ role = 'user'; content = @(@{ type = 'text'; text = $t }) } } | ConvertTo-Json -Depth 6 -Compress }
$lines = @(
  (Msg 'Remember the number 4242. Reply with only: OK'),
  (Msg '/btw What number did I ask you to remember? Answer with the number only.'),
  (Msg '/btw Use a tool to list the files in the current folder.'),
  (Msg 'What number did I ask you to remember? Answer with the number only.')
)
Push-Location $dir
$out = $lines | & $claude -p --input-format stream-json --output-format stream-json --verbose
Pop-Location
$sid = $null
foreach ($l in $out) {
  try { $j = $l | ConvertFrom-Json } catch { continue }
  if ($j.type -eq 'system' -and $j.subtype -eq 'init') { $sid = $j.session_id; 'init: btw ברשימת הפקודות = ' + ($j.slash_commands -contains 'btw') + ' | model=' + $j.model }
  elseif ($j.type -eq 'result') { 'result[' + $j.subtype + ']: ' + $j.result }
  elseif ($j.type -eq 'assistant') {
    $t = ($j.message.content | Where-Object { $_.type -eq 'text' } | ForEach-Object { $_.text }) -join ' '
    $u = ($j.message.content | Where-Object { $_.type -eq 'tool_use' } | ForEach-Object { $_.name }) -join ','
    "assistant: טקסט=[$t] כלים=[$u]"
  }
  elseif ($j.type -ne 'stream_event') { 'אחר: ' + $j.type + '/' + $j.subtype }
}
$enc = $dir -replace '[^A-Za-z0-9]', '-'
$tr = Join-Path $env:USERPROFILE ".claude\projects\$enc\$sid.jsonl"
'תמלול: ' + $tr
'שורות בתמלול שמכילות "btw": ' + (Select-String -Path $tr -Pattern 'btw' -SimpleMatch | Measure-Object).Count
'שורות בתמלול שמכילות "4242": ' + (Select-String -Path $tr -Pattern '4242' -SimpleMatch | Measure-Object).Count

איך לקרוא את התוצאה:
- "btw ברשימת הפקודות = False": הפקודה לא קיימת בגרסה שלכם (או לא מוצגת במצב הזה). אין מה לבנות עד שיוסבר.
- תשובת /btw הראשונה (שאלת "איזה מספר") אמורה להיות 4242 אם /btw רואה את הקשר השיחה. אם המודל אומר שאינו יודע:
  /btw בלי הקשר, ובמקרה כזה הפיצ'ר הוא "שאלה כללית בלי זיכרון" ולא "שאלה על מה שקרה".
- ההודעה השלישית (/btw עם בקשה להשתמש בכלי): בעמודה "כלים" אמור להיות ריק. אם מופיע שם כלי, הכלים לא חסומים.
- האם /btw נכנס להיסטוריה: הודעה רביעית (בלי /btw) שואלת שוב על המספר; היא צריכה לענות 4242 (נזכר מההודעה הראשונה).
  מספר השורות עם "btw" בתמלול אומר אם הפקודה והתשובה נשמרו (0 = לא נשמרו, כמו שמצופה מ"שאלה צדדית").
- "אחר:" שורות מראות סוגי אירועים נוספים ש-/btw מחזיר. העתיקו אותן.

א.2 (אופציונלי, במצב אינטראקטיבי, בלי התוסף) האם /btw עובד בזמן ש-Claude עובד:
1. בטרמינל, בתיקייה זמנית: claude
2. בקשו משימה ארוכה, למשל: כתוב סיפור של 40 שורות ועבור עליו אחר כך 3 פעמים.
3. בזמן שהוא עובד, הקלידו /btw מה שם התיקייה הנוכחית? ולחצו Enter.
4. רשמו: האם התשובה הופיעה מיד בלי להפסיק את העבודה? האם המשימה המשיכה?

מה להעתיק לצ'אט: תוצאת claude --version, כל פלט א.1, ותוצאת א.2 (שורה אחת).

הערה: א.1 שולח ארבע הודעות קצרות למודל, ולא נוגע בפרויקט שלכם (התיקייה נוצרת ב-TEMP). מחיקה:
Remove-Item -Recurse $env:TEMP\cl-btw-test


------------------------------------------------------------
בדיקה 4 - שיוך קבצים לשיחה ב-VS Code (כ-20 דקות)
------------------------------------------------------------
איך מריצים: בחלון ה-VS Code של התוסף (ראו 'הכנה כללית'). אם בדיקה 2 כבר רצה, תוצאותיה מסבירות את ג.3.

הכנה: פתחו את התוסף ב-VS Code (code --extensionDevelopmentPath=C:\Users\user\Claude-in-VSC) על פרויקט כלשהו, ופתחו
את היומן: Ctrl+Shift+P ואז "Claude Code Local: הצגת יומן". צרו בפרויקט שני קבצי טקסט: a.txt עם השורה "המילה היא ענבר"
ו-b.txt עם השורה "המילה היא תפוז". שיחה חדשה לכל בדיקה שמצוינת "שיחה חדשה".

ג.1 רשימת @
  1. בתיבת ההודעה הקלידו @ .  צפוי: רשימת קבצים ותיקיות של הפרויקט (בלי קבצים ש-.gitignore מתעלם מהם).
  2. הקלידו חלק משם, ובחרו a.txt עם Enter.  צפוי: בתיבה מופיע @ ואחריו נתיב מלא (C:/...).
  3. בחרו תיקייה מהרשימה.  צפוי: הרשימה מציגה את התוכן הישיר של התיקייה (אפשר לרדת עוד).
  4. ודאו שבחירה מהרשימה לא מפעילה פקודת / ולא שולחת כלום.

ג.2 קיצורים וגרירה
  1. פתחו קובץ בעורך ולחצו Alt+K.  צפוי: @ עם נתיב הקובץ נכנס לתיבה.
  2. גררו קובץ מהסייר לתיבת ההודעה כשמקש Shift לחוץ.  צפוי: @ עם נתיב מלא.
  3. גררו קובץ תמונה מחוץ ל-VS Code אל התיבה (F-11).  צפוי: תמונה מצורפת. אם לא: רשמו, ושורת [drop] מהיומן.

ג.3 מה ה-CLI עושה עם @ (תלוי בתוצאת בדיקה 2)
  1. שיחה חדשה. הקלידו @a.txt (מהרשימה) ואחריו: מהי המילה בקובץ? ענו במילה אחת. ושלחו.
  2. צפוי: ענבר. בדקו בשיחה: האם הופיעה שורת כלי "קריאה" (Read) לפני התשובה?
     - ענבר בלי שורת כלי: ה-CLI העלה את הקובץ (@ מורחב).
     - ענבר אחרי שורת כלי קריאה: המודל פתח אותו בעצמו (@ לא הורחב).
  3. שיחה חדשה, @ של תיקייה ואחריו: אילו קבצים יש בתיקייה? צפוי: רשימה בלבד, בלי תוכן הקבצים.

ג.4 כפתור מקור השיחה (קובץ או תיקייה מסייר הקבצים)
  1. שיחה חדשה.  צפוי: בשורת הכלים כפתור "מקור השיחה: ללא".
  2. לחצו עליו.  צפוי: נפתח סייר הקבצים של המערכת בתיקיית הפרויקט. בחרו a.txt.  הכפתור מציג 📄 a.txt.
  3. שלחו: מה המילה בקובץ שהתחלנו ממנו? ענו במילה אחת.  צפוי: ענבר. (ההודעה נשלחת עם ההוראה
     "זה קובץ המקור של השיחה הזו: @נתיב. קרא אותו ותתחיל לעבוד ממנו." שלא מוצגת בבועה שלכם.)
  4. שלחו עוד הודעה על הקובץ. ההוראה לא אמורה לחזור (אין דרך לראות זאת ישירות; חפשו שהתשובה עדיין מתייחסת לקובץ).
  5. לחצו שוב.  צפוי: תפריט קטן "בחירת קובץ או תיקייה אחרים…" / "הסרת המקור". בחרו אחרים ובחרו את b.txt,
     ושלחו: באיזה קובץ מתחילה העבודה? צפוי: b.txt, המילה תפוז.
  6. לחצו שוב, בחרו תיקייה (למשל תיקיית הפרויקט).  צפוי: הכפתור מציג 📁 ושם התיקייה, ולשאלה "מהי תיקיית המקור?" המודל עונה.
  7. לחצו "הסרת המקור".  צפוי: הכפתור חוזר ל"מקור השיחה: ללא", וההודעה הבאה נשלחת כרגיל.

ג.5 ללא שמירה (כמו שהוחלט: בזיכרון בלבד)
  1. בחרו a.txt, שלחו הודעה, ואז סגרו את השיחה ופתחו אותה מחדש מרשימת השיחות (☰).
  2. צפוי: הכפתור "מקור השיחה: ללא" (הבחירה לא נשמרת). זה תקין לפי ההחלטה, לא תקלה.
  3. טענו מחדש את החלון (Developer: Reload Window).  צפוי: אותו דבר.

ג.6 תמונה בלבד (F-11)
  1. הדביקו תמונה לתיבה (Ctrl+V) בלי לכתוב טקסט.  צפוי: כפתור השליחה פעיל, והשליחה עובדת.
  2. אם המודל לא תומך בתמונות, צפוי הסבר בעברית לפני שגיאת השרת.

מה להעתיק לצ'אט: לכל סעיף ג.* - עבר / נכשל, ואם נכשל מה קרה בפועל ושורות רלוונטיות מהיומן. ב-ג.3 ציינו
איזו מהאפשרויות התקבלה. ב-ג.4 ציינו אם הכפתור והבורר נראים נכון.

הערה: הבדיקות לא משנות את הפרויקט, חוץ משני קבצי הטקסט שיצרתם. ללא התקנות.

------------------------------------------------------------
בדיקה 5 - החלפת מודל וחלון ההקשר, תיקונים F-8 ו-F-9 (כ-10 דקות)
------------------------------------------------------------


למה: התיקון נבדק מול Claude Code בגרסה 2.1.317. אצלכם רצה 2.1.246, ולכן צריך לוודא שגם שם
זה עובד. הבדיקה לוקחת כ-10 דקות (כולל טעינה קרה של מודל).

שלב 0 - בדיקות היחידה (בתיקיית הפרויקט, ב-PowerShell):
