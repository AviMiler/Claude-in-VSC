בדיקה: /btw כתהליך נפרד מול ה-CLI האמיתי
=========================================

מה נבדק: התוסף מריץ כל שאלת /btw כתהליך claude קצר וחד-פעמי (לא התהליך של השיחה):
  claude -p --output-format json --tools "" --no-session-persistence   (השאלה נשלחת ב-stdin)
צריך לוודא ש-(1) הדגלים האלה קיימים בגרסה שלכם, (2) אין כלים, (3) אין היסטוריה, (4) לא נשמר כלום.
בדיקות היחידה ו-fake-claude מוכיחים רק שהתוסף שולח את הדגלים; הן לא מוכיחות מה ה-CLI עושה איתם.

שלב 1. גרסה ודגלים. הריצו ב-PowerShell:

claude --version
claude --help | Select-String -Pattern 'no-session-persistence|--tools'

צפוי: שני הדגלים מופיעים. אם אחד חסר, עצרו ודווחו (התוסף יציג שגיאה).

שלב 2. הדביקו את כל הבלוק (אם claudePath שלכם הוא נתיב מלא, שנו את השורה הראשונה):

$claude = 'claude'
$dir = Join-Path $env:TEMP 'cl-btw-proc'
New-Item -ItemType Directory -Force $dir | Out-Null
Push-Location $dir
'--- א. תשובה רגילה ---'
'What is 2+2? Answer with the number only.' | & $claude -p --output-format json --tools "" --no-session-persistence
'--- ב. בקשת כלי (צפוי: לא מריץ, מסביר שאין כלים) ---'
'Use a tool to list the files in the current folder.' | & $claude -p --output-format json --tools "" --no-session-persistence
'--- ג. היסטוריה (צפוי: לא יודע על שיחה קודמת) ---'
'What did I ask you before this message? If nothing, say NONE.' | & $claude -p --output-format json --tools "" --no-session-persistence
Pop-Location
'--- ד. אין קובץ שיחה חדש ---'
Get-ChildItem (Join-Path $env:USERPROFILE '.claude\projects') -Recurse -Filter *.jsonl | Where-Object { $_.LastWriteTime -gt (Get-Date).AddMinutes(-3) } | Select-Object FullName

צפוי:
  א. אובייקט JSON אחד עם "result":"4" ו-"is_error":false.
  ב. התשובה אינה רשימת קבצים בפועל; אין tool_use.
  ג. NONE (או שהוא אומר שאין לו הקשר).
  ד. אין קובץ jsonl חדש של התיקייה cl-btw-proc.
דווחו אם אחד מהם שונה, והדביקו את הפלט של א'.

שלב 3. ב-VS Code (Extension Development Host), בשיחה פתוחה:
  1. שלחו "זכור את המספר 4242. ענה רק: אישור". המתינו לתשובה.
  2. כתבו "/btw איזה מספר ביקשתי שתזכור?" ושלחו. צפוי: כרטיס "שאלה צדדית" שמראה "חושב..." ואז תשובה שאינה 4242 (אין היסטוריה).
  3. כתבו "/btw" לבד. צפוי: הודעה קצרה שמבקשת שאלה.
  4. שלחו "/btw" בזמן ש-Claude עונה על הודעה רגילה. צפוי: הכרטיס מופיע והתשובה הראשית לא מופרעת, אין שינוי בתור.
  5. לחצו "סגירה" על כרטיס שעדיין חושב. צפוי: הכרטיס נעלם בלי שגיאה.
  6. רעננו/עברו שיחה וחזרו: הכרטיס לא חוזר (לא נשמר). השיחה (חלון היסטוריה) לא מכילה את שאלת ה-/btw.
  7. עם מודל מקומי (gateway): אם השאלה נכשלת או תלויה, העתיקו את הטקסט מהכרטיס ואת שורות [btw] מיומן "Claude Code Local".
