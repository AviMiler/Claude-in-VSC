בדיקה 7 - מה שנבנה, ב-VS Code (כ-25 דקות)

מריצים בחלון VS Code שבו התוסף פעיל (code --extensionDevelopmentPath=...). פותחים שיחה חדשה לפני כל קבוצה. לכל סעיף: עושים, משווים ל"צפוי", ולוחצים עבר / נכשל / דילגתי. אפשר לכתוב הערה. הכול נשמר בדפדפן. בסוף "העתקת דוח" והדביקו בצ'אט.

הדוח

הטקסט כאן הוא מה שמדביקים בצ'אט. אם משהו נכשל, צרפו גם שורות מהיומן (Ctrl+Shift+P, "העתקת יומן").
