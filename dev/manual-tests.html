בדיקות ידניות - Claude Code Local

הכל כאן עדיין לא נבדק ב-VS Code אמיתי ומול ה-CLI האמיתי. סמנו לכל בדיקה: עבר / נכשל, והוסיפו הערה. המצב נשמר בדפדפן (localStorage). בסוף לחצו "העתקת תוצאות" והדביקו בשיחה.

הלוג נמצא ב-Output > "Claude Code Local" (או הפקודה "Claude Code Local: Show Log"). להעתקה: "Claude Code Local: Copy Log". לפירוט מלא הגדירו claudeLocal.logLevel = debug. שורה בלוג: HH:MM:SS.mmm [תגית] טקסט; אזהרות מסומנות WARN. הלוג לא מכיל טקסט הודעות, תוכן קבצים או ערכי משתני סביבה - רק אורכים, שמות ומזהים.
איפה עושים מה (לפני שמתחילים). בכל בדיקה, לצד הצעד מופיעה תווית שאומרת איפה לבצע אותו:
  • PowerShell חלון PowerShell רגיל של Windows, מחוץ ל-VS Code (תפריט התחל ← "PowerShell"). שם מריצים רק את פקודת ההפעלה code --extensionDevelopmentPath=... ופקודות node/where.exe. הנתיב עם רווחים חייב להיות במרכאות.
  • חלון הפיתוח (Extension Development Host): חלון VS Code חדש שנפתח אחרי פקודת ההפעלה, ובכותרתו כתוב [Extension Development Host]. כל הבדיקות מתבצעות בו, לא בחלון VS Code הרגיל שלכם. פתחו בו תיקיית עבודה כלשהי (File ← Open Folder).
  • Command Palette בתוך חלון הפיתוח: Ctrl+Shift+P, מקלידים את שם הפקודה (למשל Claude Code Local: Show Log), בוחרים ו-Enter.
  • הגדרות בתוך חלון הפיתוח: Ctrl+, ובשורת החיפוש claudeLocal. לעריכה כקובץ: Command Palette ← Preferences: Open User Settings (JSON).
  • צ'אט הצ'אט של התוסף: כפתור הדמות הכתומה (Claude) בסרגל הכלים של העורך, הפריט "✻ Claude" בשורת המצב, או Ctrl+Alt+C. כולם פותחים את אותו מקום: סרגל הצד (ברירת מחדל) או לשונית עורך אחת, לפי claudeLocal.preferredLocation. כותבים בתיבת ההודעה שלמטה ו-Enter.
  • רשימת השיחות הכפתור ☰ בפינה הימנית של כותרת הצ'אט: מגירה עם השיחות הפתוחות (גם אלה שעובדות ברקע) והשיחות הקודמות.
  • Output הלוג: בתוך חלון הפיתוח, תפריט View ← Output, ובתיבת הבחירה שבראש הפאנל בוחרים Claude Code Local. או הפקודה Claude Code Local: Show Log.
  • דפדפן הדף הזה. שם מסמנים עבר/נכשל ולוחצים "העתקת תוצאות".
צעד בלי תווית מתבצע בחלון הפיתוח (בצ'אט או בעורך), לפי מה שכתוב בו.

לא נבנה (אל תחפשו)

  • /btw (שאלה צדדית)
  • תצוגת LaTeX
  • F: הקשר העורך (בחירת שורות ב-Alt+K; כרגע נכנס רק @path של הקובץ)
  • חזרה לנקודה בשיחה עצמה (rewind-to-point) ו"שחזור קוד ושיחה" (both): רק שחזור קוד ופיצול שיחה. הודעת ה-CLI המתאימה מעולם לא נקלטה.
  • כפתור "העבר לרקע" למשימה שרצה בחזית: לא אפשרי, ל-CLI אין בקשה כזו.
