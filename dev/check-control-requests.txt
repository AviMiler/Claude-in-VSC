בדיקה: אילו בקשות בקרה ה-CLI שלך (2.1.246) יודע לעשות
==========================================================

מה זה בודק: הסקריפט מפעיל את ה-CLI בתיקייה זמנית ריקה, שולח לו בקשות שמצאנו בתוסף הרשמי
(שאלת צד, תכנית, משימות רקע, הגדרות, ייצוא ועוד), ורושם לכל אחת "נתמך / לא נתמך" ואת מבנה
התשובה (שמות שדות בלבד, בלי תוכן). בנוסף שלוש בדיקות קטנות עם המודל:
  - hooks: האם ה-CLI מודיע לנו אחרי שהמודל הריץ כלי, ואם ההערה שלנו מגיעה למודל.
  - שרת MCP "פנימי": האם ה-CLI מדבר עם שרת כלים שחי בתוך התוסף, בלי פורט.
  - appendSystemPrompt: האם הוראה שנשלחת רק בהתחלה משפיעה על התשובה.
התוצאות יקבעו אילו הצעות אפשר לבנות ואם בכלל שווה לשדרג את ה-CLI.

כמה זמן: בערך 10-30 דקות (ארבע תשובות מודל; טעינה קרה של המודל לקחה כ-285 שניות).
בטיחות: מאושר רק `echo` ב-Bash והכלי של הבדיקה עצמה. כל השאר נדחה ונרשם. לא נכתב שום קובץ
בפרויקט; נכתב רק קובץ הדוח ליד הסקריפט ותיקייה זמנית ב-%TEMP%.

שלבים
-----
1. שמור את הקובץ probe5-standalone.txt בתיקייה כלשהי, למשל C:\probe, ושנה את שמו ל-
   probe5-standalone.js

2. פתח PowerShell ועבור לתיקייה:
   cd C:\probe

3. הרץ (שורה אחת; החלף את הנתיב אם claude-bin.exe נמצא במקום אחר, `where.exe claude` מראה):
   node probe5-standalone.js --claude "C:\Users\206861775\AppData\Local\Programs\ClaudeCode\claude-bin.exe"

   חשוב: הנתיב הוא של claude-bin.exe, לא של claude.cmd.
   אם רוצים קודם בדיקה קצרה בלי המודל (כדקה):
   node probe5-standalone.js --claude "<הנתיב>" --only c1
   (שים לב: גם ב-c1 הבקשה side_question עשויה להפעיל את המודל.)

4. חכה. כל כמה שניות מודפסת שורת התקדמות ("still waiting"). בסוף מודפס "===== summary =====".
   אם המודל איטי מאוד והבדיקות נגמרות ב-"timed out", הרץ שוב עם --turn-timeout 700

5. העתק את הסיכום ושלח לי:
   - הדרך הקצרה: סמן והעתק את כל מה שמופיע מתחת ל-"===== summary =====".
   - הדוח המלא (עדיף): Get-Content probe5-report.json -Raw | Set-Clipboard   ואז הדבק.
   לפני שליחה: הדוח מכיל רק שמות שדות וסוגים, בלי ערכים. בכל זאת שווה להעיף מבט.

6. ניקוי (אחרי ששלחת):
   Remove-Item -Recurse -Force "$env:TEMP\claude-probe5-*"
   וגם התיקיות ב-%USERPROFILE%\.claude\projects ששמן מכיל claude-probe5 (התמלילים של הבדיקה).

איך קוראים את הסיכום (לידיעה, אני אפרש)
-------------------------------------
  supported                 = ה-CLI מכיר את הבקשה וענה.
  unsupported               = "Unsupported control request subtype": הגרסה לא מכירה אותה.
  error: ...                = כנראה מכיר אותה אבל דחה את הנתונים (למשל משימה שלא קיימת).
  no answer (timeout)       = לא ענה בזמן.
  hooks ... hook_callback=true       = ה-CLI מודיע לנו אחרי כלי.
  sdk_mcp ... mcp_message=true       = שרת כלים פנימי עובד.
  appendSystemPrompt obeyed=true     = ההוראה ההתחלתית הגיעה למודל.

בעיות נפוצות
-------------
  "not recognized" / ENOENT        → הנתיב ל-claude-bin.exe שגוי. בדוק עם where.exe claude
  "initialize ... timed out"       → נסה claude-bin.exe --version ידנית.
  הדבקה של כמה שורות נחתכה         → הדבק כל פקודה לבד.
