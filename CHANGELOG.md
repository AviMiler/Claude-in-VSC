# Changelog

Newest first. Each entry: what changed + why. Dates are commit dates.

## 2026-11-01 (package C: prompt box, partial)
- **Built:** Auto permission mode in the picker with the Hebrew warning; grouped `/` menu (commands, skills, "בטרמינל בלבד" greyed out) with the "זמינה רק בטרמינל" card and an open-in-terminal button, terminal-only commands never sent; visible message queue (grey "ממתין" bubbles with cancel) and per-conversation up-arrow history; copy button under each answer; @-mentions for files and folders (`git ls-files` when `respectGitIgnore`, folder walk otherwise); Alt+K inserts `@path` of the open file; `/plan` (switches to plan mode) and `/plan open` (read-only virtual Markdown document, no file written; plan text = assistant text of the turn that reaches `ExitPlanMode`) plus an "open plan" button; pasted/dropped images sent as base64 image blocks (all models, no gating); files dragged in become `@path` mentions (a PDF is read by the CLI).
- **Why the queue is client-side:** cancelling a queued message only needs removing it before it is sent, so no `interrupt_cancel_queued_v1` message is used (its exact shape was never captured; protocol work is Opus territory). The message is sent when the previous turn's `result` arrives. Consequence: a queued message is not in the CLI yet, so it is lost if the process dies first.
- **New files:** `webview/chat/prompt-logic.js` (pure: command grouping, queue, history, image check), `webview/chat/mention-menu.js`, `src/panels/mentions.js`, `src/panels/plan-doc.js`; tests `prompt-logic`, `mentions`. New setting `respectGitIgnore`, command `claude-local.insertAtMention` (Alt+K, `cmd+alt+k` on Mac).
- **Not built (remaining from package C):** `/btw` (needs a check of how to run a tool-less, history-less side question against the real CLI), LaTeX (needs a bundled KaTeX in `webview/vendor`), Alt+K selected lines (package F). Plan-approval buttons stay postponed.
- **Not verified:** nothing ran inside real VS Code or against the real CLI: `@path` text is sent as-is (whether the CLI expands it in stream-json is unknown; the model can read the file), image blocks, the virtual plan document, Alt+K, drag/drop. Unit tests 46/46.

## 2026-11-01 (package A: settings and shortcuts)
- **New settings:** `environmentVariables` (merged over the CLI environment, defaults `API_TIMEOUT_MS=1200000`, `CLAUDE_ENABLE_STREAM_WATCHDOG=0`, `CLAUDE_CODE_MAX_CONTEXT_TOKENS=64000`), `preferredLocation`, `lockEditorGroups`, `useTerminal`, `enableNewConversationShortcut`, `keybindings.send/newLine/rewind` (webview-side; `useCtrlEnterToSend` kept and swaps the defaults). Why: the local model needs the long timeout and the real 64,000 window, and the user asked for placement and shortcut control (`PLAN.md` sections 3-4).
- **New commands and shortcuts:** Open in Terminal (`terminal.open`), Keyboard Shortcuts (opens the shortcut editor filtered to `claude-local`), `focusToggle` on Ctrl+Esc (editor to chat; does not toggle back from the sidebar), Ctrl+N for a new conversation (opt-in, only with chat focus). Ctrl+Shift+Esc and Ctrl+Alt+C kept. Why: all VS Code-level shortcuts must be rebindable.
- **Code:** new `src/cli/env.js`, `src/cli/terminal.js`, `src/util/workspace.js` (`workspaceCwd` moved out of `conversation.js`), `webview/chat/keys.js`; `SETUP.md` section 7 (Hebrew).
- **Deviations from the plan:** `useTerminal` applies to `editor.open` and `editor.openLast`; the `rewind` key is matched but only calls the hook `CL.composer.onRewind` until package B (checkpoints); Ctrl+Esc has no context key.
- **Known limits:** VS Code replaces the whole `environmentVariables` object when the user sets one key. **Not verified in real VS Code:** the new commands, the Ctrl+N `when` clause, key forwarding from the webview, and the Ctrl+Esc Start-menu conflict (user item, `SETUP.md` section 7). Unit tests 32/32.
