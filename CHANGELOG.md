## 2026-11-05 (F-8 model switch loads two models, F-9 context meter 1,000,000)
- **F-8, root cause:** the CLI applies the `env` of its settings files over its own process environment, so the `ANTHROPIC_DEFAULT_*_MODEL` variables package D set on the process lost against `~/.claude/settings.json` and the session-title call stayed on `qwen3.8:27b`. **Fix:** the model aliases (`ANTHROPIC_DEFAULT_{OPUS,SONNET,HAIKU}_MODEL` and `ANTHROPIC_SMALL_FAST_MODEL`, which the title call reads first) now go through `--settings '{"env":{...}}'` (flag settings beat user settings). `modelEnv` was replaced by `launchSettings` in `src/models/launch.js`; `buildArgs` takes `settings`.
- **F-9, root cause:** without `--model` the CLI resolves the default to `qwen3.8:27b[1m]`, and the `[1m]` suffix sets a 1,000,000 window before `CLAUDE_CODE_MAX_CONTEXT_TOKENS` is read. **Fix:** when `environmentVariables` holds a window, `--settings` also carries it and `CLAUDE_CODE_DISABLE_1M_CONTEXT=1`; the meter caps the CLI's `maxTokens` at the configured window as a safety net and logs `(CLI max=…, capped) model=…` when it does.
- **How it was checked:** against the real CLI 2.1.317 on the dev machine (isolated config dir, settings.json like `SETUP.md`, a local PowerShell stand-in for the Messages API): both bugs reproduced, both fixed by the new arguments (`DEPENDENCIES.md` rows #39, #40). New pure functions, the meter cap and the fake CLI were checked in a browser harness (34 checks); the `.cmd` quoting of the JSON argument with a compiled argv echo. **The unit tests were not run** (no Node on the dev machine); tests were updated/added: `models` (launchSettings, contextWindow, cap), `args` (`--settings`), `conversation` (F-8 against a simulated settings.json, F-9 default model 64,000, no window keeps the CLI value).
- **Fake CLI:** reads `--settings` JSON `env` over a simulated settings.json (`FAKE_CLAUDE_USER_SETTINGS_ENV`) over the process env; invalid JSON exits 1; without `--model` the model is `fake-model[1m]` (1,000,000) unless 1M is off; `get_context_usage` returns `model`; `fake_default_models` adds `ANTHROPIC_SMALL_FAST_MODEL`.
- **Docs:** `spec.md` (spawn, environment precedence, meter, model pill, verification), `DEPENDENCIES.md` (#28 updated, #39, #40, section 5), `DECISIONS.md`, `SETUP.md` (precedence sentence), new `dev/check-model-switch.txt` for the user.
- **Not verified:** the user's CLI 2.1.246 (that `CLAUDE_CODE_DISABLE_1M_CONTEXT` exists there and does not break a `"model"` with `[1m]` in settings.json; a bug of that shape was fixed in 2.1.307), `/api/ps` showing one model after a switch, real VS Code.
